# Exercise Data Analysis & Visualization

## Project Overview

This project analyzes an exercise dataset using **Tableau** to transform structured exercise data into visual insights.

The repository contains the source Excel dataset and a packaged Tableau workbook.

## Objectives

The project demonstrates:

- Data exploration
- Exercise-data analysis
- Aggregation and comparison of available exercise measures
- Tableau visualization
- Interactive dashboard development
- Data storytelling

## Technology Stack

| Technology | Purpose |
|---|---|
| Tableau | Dashboard and visualization |
| Excel | Source dataset |

## Dashboard

The Tableau workbook contains the visual analysis built from the Exercise.xlsx dataset.

The dashboard is intended to support exploration of the exercise-related measures contained in the source data.

## Analytical Areas

The project focuses on comparing the exercise measures available in the dataset and presenting them through visual summaries.

Typical analytical questions supported by the workbook include:

- How do exercise records differ across the available categories?
- Which categories show higher or lower activity?
- How are exercise measures distributed?
- What patterns can be identified through visual comparison?

## Data Limitation

The repository exposes the workbook and source Excel file, but the GitHub repository does not contain a separate data dictionary describing every field.

Therefore, this README intentionally avoids inventing field definitions or numerical findings that are not documented in the repository.
