- ₹15.42M equivalent delivered gross order value in the analyzed dataset

## Data & Reproducibility Notes

The portfolio uses a mixture of public, fictional, synthetic, demonstration, and controlled datasets.

- Some projects use publicly available datasets.
- The Employee Attrition project uses a fictional IBM HR dataset.
- The Healthcare project uses the 100-patient MIMIC-IV demonstration dataset.
- The Supply Chain project uses a synthetic/high-dimensional supply-chain dataset.
- The Logistics project uses both a public reference dataset and a controlled hypothetical dataset depending on the project week.
- The FinTech project does not include the raw UCI dataset in the repository.
- Dataset-specific limitations and sourcing information are documented within individual project folders.

Findings should therefore be interpreted in the context of each project's dataset and scope.
